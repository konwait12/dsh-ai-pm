## 说明

- **适用场景**：需要「年月/时间」粒度的选择器组件，尤其是**数据看板按时间筛选**（跨板块统一口径）或**定时/计划类提交**（带合法性校验）场景。组件默认只负责「半屏弹窗 + 滑动选择 + 默认当前年月 + 范围声明」四件事，业务合法性规则作为扩展行按需启用。
- **来源案例**：
  - REQ-008-bae（FUN-009 时间选择组件）：FEA-009（跨 5 板块年月选择，默认当前年月）/ BR-024（时间选择范围）/ BR-025（时间默认值）/ STATE-006（滑动选择+确认→时间生效）/ EX-005（取消）/ AC-013 / 字段定义（默认当前年月、滑动选择确认后生效）。
  - REQ-006-service-account（FUN-008 定时发送时间）：BR-015（定时发送 10 分钟规则）/ EX-006（定时时间不合法）/ AC-012 / 字段定义（开始 ≥ 当前+10 分钟；结束 ≥ 开始+10 分钟）——作为「业务侧合法性规则」扩展行的来源。
- **使用方式**：复制到 function-description 对应章节表格时——① 将 `FUN-XXX` 改为目标产物中的实际 FUN 编号（如 FUN-009）；② BR/AC/EX ID 改为目标产物内单调递增编号；③ 「来源」列保留本片段路径，并可追加原始 SRC 追溯；④ 跨页面范围声明必须按目标案例实际列出覆盖板块，不得照抄；⑤ 仅当目标案例为定时/计划类提交时启用 BR-XXX-4 / EX-XXX-2 扩展行，否则删除并注明。
- **知识状态**：BR-XXX-1~3 为 FACT（组件交互形态与默认值来自已跑测案例）；BR-XXX-4 为案例特定业务规则，启用时须由业务事实负责人确认口径。
- **关联**：组件型 FUN 规则密度天然不足（BR < 3 触发 rule_density HIGH 告警），本片段自带 4 条 BR 满足密度下限，对应 OBS-008 优化方向。
