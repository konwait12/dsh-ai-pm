# 人类审查清单 · PRD 汇总

> PM/业务方/技术负责人/测试负责人审查最终 `prd.md` 时使用。

## 完整性
- [ ] §0 上游产物清单：4 个上游产物是否全部 confirmed？
- [ ] §1-§4（项目背景/旅程/UX/功能描述）：所有内容是否与上游 confirmed 版本一致？有没有被改写或遗漏？

## 追溯性
- [ ] §6 RTM：P0 目标→故事→功能→详述→验收→业务规则 的链是否完整？
- [ ] §7 正向追溯检查：是否有"目标无故事"、"故事无功能"、"功能无详述"、"详述无验收"的断裂？
- [ ] §8 反向追溯检查：是否有孤儿元素（有 AC 但无 FUN、有 FEA 但无 ST）？

## 一致性
- [ ] §9 不一致报告：如果为空——真的没有不一致吗？还是有但没发现？
- [ ] §9 如果不为空——每条不一致是否有建议处理方式？有没有被静默修复的？

## 范围控制
- [ ] PRD 中有没有**上游 confirmed 产物中没有出现过**的新增需求/功能/故事？
- [ ] 如果有——这是否经过了正式的变更请求流程？

## 最终判断
1. 你可以直接拿这份 PRD 去**立项评审会**吗？
2. 你可以直接拿这份 PRD 交给**开发团队开始估算**吗？
3. 你可以直接拿这份 PRD 给**测试团队写测试用例**吗？
