# 三阶段

| 目录 | 阶段 | 做什么 | 包含的 Skill |
|---|---|---|---|
| `001-business-requirements` | 业务需求 | 搞清楚为什么要做、谁参与、业务流程是什么 | project-background-goal, user-journey-and-stories |
| `002-product-requirements` | 产品需求 | 把业务需求变成系统功能和交互规则 | product-ux, function-description |
| `003-prd-output` | PRD 输出 | 汇总已确认内容，验证一致性，输出最终 PRD | prd-assembly |

每个阶段有 `STAGE.md`（英文执行规范）定义了该阶段的目标、入口条件、产出物和禁止项。

主线只走这三个阶段。可行性分析、竞品调研、多方案对比等属于支持能力，按需触发，不占主干。
