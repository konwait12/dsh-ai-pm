# 人类审查清单 · 竞品调研

> 本清单给 **PM/业务方** 在审查 AI 产出的 `competitive-analysis.md` 时使用。
> 不是给 AI 看的（AI 看 `audit-checklist.md`）。
> 每条 = "是 / 否 / 不适用"，有"否"则进入 Revision 修改确认。

## 正确性
- [ ] 竞品选择是否合理？直接/间接/参照竞品各选对了没有？有没有漏掉真正威胁大的竞品？
- [ ] 每个竞品的信息是否来自可靠来源（官网/应用商店/权威报告）？SRC-* 位置和检索日期是否标注？
- [ ] 竞品功能的描述（有没有、怎么实现的）是否与来源一致，而不是 AI 脑补？

## 完整性
- [ ] 调研目标（业务级/功能级）是否明确？所有对比维度是否都服务这个目标？
- [ ] 是否覆盖了我们真正关心的维度？（对照背景基线里的目标逐条检查）
- [ ] 结论里有没有"我们应该做 X / 差异化做 X / 忽略 X / 还不知道 X"四项齐全？

## 一致性
- [ ] 横向对比的结论和逐品分析的证据是否自洽？结论有没有引用逐品分析里没写的内容？
- [ ] 每条"我们应该做 Y"是否对应一个已确认的目标？还是无目标背书的自嗨？

## 可测性
- [ ] "So What"结论是否具体到可执行（做哪个功能/不做哪个功能/差异化维度）？而不是"提升竞争力"这类空话？
- [ ] 如果产品经理照此执行，是否知道先做哪一条、不做哪一条？

## 可维护性
- [ ] 来源追溯是否覆盖全部竞品？有没有无来源的"事实"声明？
- [ ] 竞品功能结论是否明确标了 `AI_INFERENCE`？有没有被当成已确认事实？

## 可追溯性
- [ ] 结论能否被 `user-journey-and-stories` / `product-ux` 直接使用（目标 ID + 差异化方向）？
- [ ] 竞品信息是当前状态吗？检索日期是否足够近？竞品近期有没有重大改版？

## 最终判断
看完这份产物后，回答这两个问题：
1. **你认同这些竞品结论吗？** 如果认同，基于产物的哪些证据？如果不认同，缺什么？
2. **你能直接拿这份竞品分析去和团队/业务方讨论产品方向吗？** 如果可以，哪些部分还需补充？如果不可以，缺什么？
